# What Happens When… — The Series (offline portal)

A self-contained library of "What Happens When…" reference volumes — spoken-ready
mechanism walk-throughs across platform/DevOps, cloud, data & streaming, languages,
AI, and robotics. Built to run entirely from local files: **no server, nothing to install.**

## How to open

Double-click **`index.html`** (or open it in any browser). That's the portal — every
volume is a card; click one to open it. Each volume has a **"← Index"** link at the
top-left to come back.

Everything works fully offline. An internet connection only makes the web fonts load;
without it, the pages fall back to clean system fonts and look almost identical.

## Printing to PDF / A4

Open a volume and print (Ctrl/Cmd-P) → "Save as PDF" or print to A4. The page is set
up for A4 with sensible margins; the theme toggle, nav link, and search/filter bar are
hidden automatically, and cards are kept from splitting across pages.

## Adding a future "What Happens When…" volume

1. Put the new standalone `.html` file into this folder
   (e.g. `whathappens-terraform.html`).
2. Open **`volumes.js`** and add one entry to the `WHW_VOLUMES` array — copy an
   existing block and edit the fields:

   ```js
   {
     id: "terraform",
     file: "whathappens-terraform.html",
     emoji: "🌍",
     title: "Terraform & IaC",
     tagline: "One-line description shown on the card.",
     group: "platform",          // reuse a group key, or add one to WHW_GROUPS
     accent: "#3A6EA5",          // card's left-border / accent colour
     scenarios: 30,
     tracks: 6,
     tags: ["state", "modules", "drift", "plan/apply"]
   }
   ```

3. Re-open `index.html`. The new card appears automatically, the totals update, and
   the topic filter picks it up. No build step, no server.

If the volume belongs to a brand-new topic, also add a `{ key, label }` entry to
`WHW_GROUPS` at the top of `volumes.js`.
